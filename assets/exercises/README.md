# Exercise photographs

Photographs from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), pinned to revision `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`. The upstream project describes its dataset and imagery as public domain under the Unlicense; its license text is retained in LICENSE-Unlicense.txt.

Exact source URLs, checksums and exercise mappings are recorded in sources.json. Photos illustrate the named exercise or the variant explicitly described in the interface, not a personalized technique assessment. Entries without a matching photograph deliberately display a missing-photo message.
